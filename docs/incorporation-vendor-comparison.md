> ⚠️ 料金・条件は変動します。**2026 年時点の一般的な目安**として扱い、契約前に必ず公式の最新情報を確認してください。

## 1. バーチャルオフィス(VO)

### 選定の最重要基準(優先順)
1. **登記可能**であること(住所を本店登記に使える)
2. **法人口座開設に強い**こと(銀行紹介・開設サポートの有無=ここが命)
3. **郵便物の転送・受取**(頻度・通知方法)
4. **電話番号/電話転送**の要否
5. 料金・初期費用・最低契約期間
6. 立地(都心一等地住所は信用面でプラス)

### 比較観点テンプレート(候補を 3 社ほど入れて埋める)

| 電話番号付与 | | | |

### 検討候補(例・要最新確認)
- **口座開設サポートが手厚いタイプ**:法人口座開設の支援・銀行紹介を売りにする VO(ひとり社長・新設法人向け)。本ケースの最有力。
- **低価格・登記特化タイプ**:月額が安く郵便転送中心。コスト重視だが口座開設は自力。
- **都心一等地・信用重視タイプ**:住所のブランド力。料金は高め。

> 本ケースの推奨:**「口座開設サポートが手厚い VO」**を第一候補に。新設法人 × VO は口座審査がネックになりやすいため、ここを最優先で潰す。

## 2. 法人口座(銀行)

### 前提
- **VO 本店は審査が厳しめ**。事業実態(HP・事業計画・契約/請求の実績)を示せると通りやすい。
- ⚠️ **資本金 1 万円(極小資本)× VO は審査の最難関**。資本金の薄さを**事業実態の資料で補強**することが必須(下記チェック参照)。まず通りやすいネット銀行を狙う。
- **2 行体制**(ネット銀行 + 将来メガ/地銀)を見据え、まずは通りやすいネット銀行から。

### 比較観点

| 観点 | ネット銀行 | メガバンク | 地銀/信金 |
|------|-----------|-----------|-----------|
| 審査の通りやすさ(新設×VO) | ◎ 比較的通りやすい | △ 厳しめ | ○ 対面で相談可 |
| 口座維持・振込手数料 | ◎ 安い | △ 高め | ○ |
| 開設スピード | ◎ 早い(オンライン) | △ | ○ |
| 対外信用 | ○ | ◎ | ○(地域) |
| 会計ソフト連携(API) | ◎ | ○ | △ |

### 検討候補(例・要最新確認)
- **GMO あおぞらネット銀行** … 新設法人・ひとり社長に実績、API 連携◎
- **住信 SBI ネット銀行(法人)** … 手数料安・連携◎
- **PayPay 銀行 / 楽天銀行(法人)** … オンライン完結
- 将来:メガバンク/地銀を信用補強用に追加検討

> 本ケースの推奨:**まずネット銀行(GMO あおぞら 等)で 1 行確保** → 事業実績が積み上がってからメガ/地銀を追加。

### 開設審査で用意すると通りやすいもの
- [ ] 事業内容のわかる Web サイト/会社案内
- [ ] 取引の実在を示す資料(見積・請求・契約のサンプル)
- [ ] 登記事項証明書・印鑑証明書・定款
- [ ] 事業計画の概要(売上見込み等)

## 3. 会計ソフト

### 選定基準
1. **銀行/カード連携**の自動取込(記帳工数を激減)
2. **税理士との共有**しやすさ(顧問が同じソフトを使えるか)
3. **インボイス未登録・免税事業者**の運用に素直に対応
4. 料金・使いやすさ

### 比較

| 観点 | freee 会計 | マネーフォワード クラウド | 弥生会計 オンライン |
|------|-----------|--------------------------|--------------------|
| 思想 | 簿記知識なくても使える設計 | 実務・税理士連携に強い | 老舗・税理士利用者が多い |
| 銀行/カード連携 | ◎ | ◎ | ○ |
| 税理士の対応率 | ○ | ◎(対応事務所が多い) | ◎ |
| ひとり法人の料金感 | 中 | 中 | 初年度無料プラン有 |
| 給与計算(役員報酬を取る場合) | オプション有 | オプション有 | 別製品 |

> 本ケースの推奨:**選ぶ税理士が使うソフトに合わせる**のが最適(顧問連携が一番効く)。税理士未定なら、連携対応事務所が多い **マネーフォワード** か、独力運用しやすい **freee** が無難。
