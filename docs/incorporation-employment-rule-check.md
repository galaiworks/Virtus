# 本業 就業規則チェックリスト(役員兼業の可否確認)

> 要件定義書 8 章 C-9 の生命線タスク。**設立着手前に必ず確認**。
> 本人は給与所得者であり、**取締役就任は登記で公示される**ため、本業先の規定との抵触を事前に潰す。

---

## なぜ最優先か

- 取締役就任は登記簿に載り、**誰でも閲覧可能**(隠せない)。
- 本業先が副業・役員兼任・競業を禁止していると、**懲戒・信頼関係毀損**のリスク。
- 設立後に発覚 → 会社を作った後で身動きが取れなくなる最悪パターンを避ける。

- [ ] 副業・兼業規程(別規程がある場合)

- [ ] 入社時に署名した誓約書類

---

## チェックポイント

### A. 副業・兼業そのもの
- [ ] 副業は「禁止」か「許可制(届出・承認)」か「自由」か
- [ ] **役員就任(取締役等)**が副業の定義に含まれるか
- [ ] 許可制の場合、**申請先・様式・承認の流れ**
- [ ] 無報酬なら可、報酬ありは不可、等の条件があるか(→ 役員報酬ゼロ方針との整合)

### B. 競業避止
- [ ] 本業と**同業・競合**にあたる事業が禁止されているか
- [ ] galaiworks の事業(AI/SaaS/コンテンツ/運用代行)が本業と競合と見なされ得るか
- [ ] 在職中だけでなく**退職後**の競業制限の有無(将来の独立に影響)

### C. 利益相反・職務専念
- [ ] 勤務時間中の従事禁止(当然順守)
- [ ] 会社の信用・名誉を害する行為の禁止条項
- [ ] 本業の顧客・情報・資産を新会社で使わないこと(機密保持)

### D. 手続き
- [ ] 申請が必要なら、**設立前に申請・承認を取得**
- [ ] 承認の記録(メール・書面)を保管

---

## 判定の目安

| 状況 | 対応 |
|------|------|
| 副業自由・競業に当たらない | そのまま設立着手 OK |
| 許可制 | **設立前に申請・承認**を取得してから着手 |
| 役員就任のみ禁止/競業に当たる懸念 | 人事に相談、または**役員でなく出資のみ/事業内容の調整**等を検討 |
| 全面禁止 | 設立可否・時期を再検討(専門家・本業先と相談) |
