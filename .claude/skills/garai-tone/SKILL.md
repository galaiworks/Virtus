# Garai Tone

galaiworks 独自の執筆スタイルガイド。

---

## 基本原則

第一に、**結論先出し**。最初の 2 行で何を伝えるかを示す。

第二に、**具体例必須**。抽象論で終わらせない、必ず数字または具体例を 1 つ以上含める。

第三に、**数字を多用する**。「いくつか」ではなく「3 つの」、「多くの」ではなく「85% の」。

第四に、**読者を動かす**。最後に必ず CTA(次に取るべき行動)を配置。

---

## 文体ルール

### 一文の長さ

```
推奨: 40 文字以内
最大: 60 文字
```

長文は分割する。

```
✗ 「AIの活用は今や経営者にとって重要な課題であり、特にひとり社長のような少数精鋭の組織では避けて通れない領域となっており、その判断が事業の成長を左右する。」

○ 「AIの活用は経営者にとって重要な課題です。
特にひとり社長は避けて通れません。
その判断が事業の成長を左右します。」
```

### 段落の長さ

```
推奨: 3-5 文
最大: 7 文
```

長い段落は読まれない。

### 強調表現

```
○ 文の構造で強調する
○ 「結論から言うと」「ここが本質です」等の文頭強調
✗ 過度な太字、色付け
✗ 「絶対」「必ず」「100%」(法令リスク)
```

### 親近感の出し方

```
○ 「〜です」「〜ます」基調
○ 適度な「率直に言います」「正直に言います」
○ 「あなた」「皆さん」を時々使う
✗ 過度な敬語、堅すぎる文体
✗ 過度な口語、軽すぎる文体
```

### 専門用語の扱い

```
○ 使うが必ず噛み砕く
○ 「BYOK(顧客が自分のAPIキーを使う方式)」のように補足
✗ 専門用語の連発
✗ 専門用語の言い換えなし
```

## 構造パターン

### note 記事の標準構造

```
1. 導入(2-3 段落)
   - 問題提起
   - なぜ今これを語るか
   - この記事で何が分かるか(箇条書き)

2. 本論(5-8 段落)
   - 各論点を「第一に、第二に、第三に」で展開
   - 各論点に具体例または数字
   - 適度に小見出し

3. 結論(2-3 段落)
   - 本論のまとめ
   - 読者への問いかけ
   - 次に取るべき行動(CTA)
```

### X 投稿の標準構造(140文字以内)

```
[結論または衝撃的な事実]

[補足 1 文]

[気づき/学び]

[CTA: フォロー、リンクへの誘導等]
```

### 営業メールの標準構造

```
件名: 具体的なベネフィット(40文字以内)

[相手の状況への言及](2-3 文)

[こちらが提供できる価値](3-4 文)

[具体的な提案](2-3 文)

[CTA: 30分のMTG等]

[署名]
```

## 良い例 / 悪い例

### note 記事の冒頭

```
✗ 悪い例:
「AIエージェントについて考えていきたいと思います。
AIエージェントとは、自律的にタスクを実行する..."

○ 良い例:
「ひとり社長が月商 100 万円を超えるには、
AI エージェントチームが必要です。
理由は 3 つあります。」
```

### CTA

```
✗ 悪い例:
「ぜひフォローしてください。」

○ 良い例:
「明日からの 3 つの実践ステップは、
LINE登録者限定で配布しています。
プロフィール欄から登録いただけます。」
```

## 顧客のブランドDNAとの統合

Garai Tone は**構造ガイド**です。実際の文体は顧客のブランドDNAに合わせます。

```python
def apply_garai_tone_with_brand_dna(content_outline, brand_dna):
    """
    Garai Tone の構造を保ちつつ、顧客の voice で書く
    """
    structure = apply_garai_structure(content_outline)
    
    # 語尾を顧客の voice に合わせる
    structure = adjust_tone_to_brand(structure, brand_dna.voice)
    
    # 語彙を顧客の vocabulary に合わせる
    structure = adjust_vocabulary(structure, brand_dna.voice.vocabulary)
    
    # 顧客の forbidden を避ける
    structure = remove_forbidden(structure, brand_dna.forbidden)
    
    return structure
```
