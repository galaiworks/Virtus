# IMPACT v2.0R フレームワーク

galaiworks の論理的説得力を最大化するコンテンツ構造。

---

## 構造

| セクション | 役割 | 配点比率 |
|----------|------|---------|
| **I**nsight | 洞察:なぜ今これが重要か | 15% |
| **M**echanism | 仕組み:どうやって実現するか | 25% |
| **P**roof | 証拠:なぜ信じられるか | 20% |
| **A**pplication | 適用:どう使うか | 20% |
| **C**onclusion | 結論:何をすべきか | 10% |
| **T**ransition | 次の行動:CTA | 10% |

## I: Insight(洞察)

### 目的
読者に「なぜ今これを読むべきか」を 30 秒以内に理解させる。

### 構造
```
1. 衝撃的な事実または数字(1-2 文)
2. なぜそれが起きているのか(2-3 文)
3. 読者にとっての意味(1-2 文)
```

### 例
```
「ひとり社長の85%が、本来やるべき経営判断ではなく、
SNS 投稿や DM 返信に時間を奪われています。

これは AI ツールがまだ『部分最適』にしか対応できていないからです。
SNS だけ、メールだけ、提案書だけ、と分断されています。

つまり、ひとり社長が『時間を取り戻す』には、
分断されたツールではなく、統合された仕組みが必要なのです。」
```

### NG パターン
- 自己紹介から始める
- 「こんにちは!今日は〇〇について書きます」
- 抽象論で始める

## M: Mechanism(仕組み)

### 目的
「どうやって実現するか」を論理的に説明する。

### 構造
```
1. 全体の仕組み(俯瞰図)
2. 各構成要素の役割
3. 連携パターン
4. なぜこの仕組みが効くのか
```

### 例
```
Virtus は 8 体の AI エージェントから構成されます。

第一に、Lead Strategist。戦略を立て、全体を指揮します。
第二に、Researcher。情報を収集します。
第三に、Drafter。コンテンツを書きます。
第四に、Designer。ビジュアルを作ります。
第五に、Distributor。配信します。
第六に、Connector。関係を構築します。
第七に、Analyst。結果を分析します。
第八に、Guardian。品質を保証します。

これらが、Anthropic 公式の Orchestrator-Worker パターンで連携します。
Lead Strategist が司令塔となり、他の 7 体に指示を出す構造です。

なぜこれが効くのか?

専門特化されたエージェントが連携することで、
1 つの AI に全部やらせる場合より、各領域で高品質な出力が得られるからです。
```

## P: Proof(証拠)

### 目的
読者に「これは本物だ」と信じさせる。

### 構造
```
1. 海外事例
2. データ・統計
3. 自身の実績
4. 顧客の声(可能であれば)
```

### 例
```
このアーキテクチャは机上の空論ではありません。

海外では、Sierra($10B 評価額/約 1 兆 5,000 億円)、
Decagon($4.5B 評価額/約 6,750 億円)が同じパターンで構築され、
ARR は 225 億円、52.5 億円に達しています。

galaiworks 自身も、SEO で 80 件以上の 1 位獲得実績があります。
1 つのエージェントだけでは出せない、複数の専門特化エージェントの
連携による品質を、実証してきました。

Founding Member の○○さんは、Virtus 導入 3 ヶ月で
リード獲得が月 5 件から月 50 件に増加しました(10 倍)。
```

### 重要原則
- 数字には**必ずソース**(自身の場合は明示)
- 海外事例は**評価額・ARR を併記**
- 顧客事例は**実名 or 匿名+業界明示**

## A: Application(適用)

### 目的
読者が「自分の場合どう使えばいいか」を具体的に理解する。

### 構造
```
1. 適用シナリオ A(コーチ業界の場合)
2. 適用シナリオ B(コンサル業界の場合)
3. 適用シナリオ C(専門職の場合)
4. 自分のケースで考えるポイント
```

### 例
```
Virtus の適用方法を、業種別に見てみましょう。

【コーチ業界の場合】
朝、Researcher が業界トレンドを集めます。
Drafter が note 記事を執筆。
Designer が Instagram カルーセルを作成。
Distributor が午後 3 時に配信。
Connector が DM 返信ドラフト。
1 日のオーナーの稼働は、承認のみで 1 時間以内。

【コンサル業界の場合】
Researcher が PR タイムズから IT 系の資金調達企業を抽出。
Drafter が個別カスタマイズした営業メールを生成。
Distributor が Gmail 経由で配信。
1 日 50 通の能動営業が、オーナー労働 30 分で完了。

【専門職(税理士、弁護士等)の場合】
Researcher が法改正情報を毎日収集。
Drafter がブログ記事と LINE 配信を作成。
Connector が個別相談 DM への返信ドラフト。
専門家としての発信が、本業を圧迫せずに継続。
```

## C: Conclusion(結論)

### 目的
本論を 3 行でまとめる。

### 構造
```
1. 1 行サマリー
2. 重要な学び 3 つ(箇条書き)
3. 残された問い
```

### 例
```
ひとり社長が「労働時間ゼロで月商 100 万円」を実現するには、
分断されたツールではなく、統合された AI チームが必要です。

重要な学び:
- 海外では既に 1 兆円規模の市場が立ち上がっている
- 8 体エージェントは Anthropic 公式アーキテクチャ準拠
- 適用方法は業種ごとにカスタマイズ可能

残された問い:
- あなたの事業ではどう適用できるか?
- 30 名限定の Founding Member 枠に応募するか?
```

{proof}

{application}
