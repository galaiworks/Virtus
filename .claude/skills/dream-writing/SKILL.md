galaiworks 独自の、読者を動かす執筆フレームワーク。

---

---

## 三層ニーズ分析

読者の頭の中には 3 層のニーズが存在します。

### 第一層: 表層ニーズ(自覚されている悩み)

```
例: 「集客に困っている」
   「SNS 運用が回らない」
   「営業効率が悪い」
```

これは検索クエリやアンケートで出てくるニーズ。

### 第二層: 潜在ニーズ(自覚していない真の悩み)

```
例: 「労働時間を減らしたい」
   「自分の時間が欲しい」
   「家族との時間が欲しい」
```

これは深掘り対話や行動観察で見えるニーズ。

### 第三層: 究極ニーズ(人生の目的レベル)

```
例: 「人生で本当にやりたいことに集中したい」
   「自分のビジネスに誇りを持ちたい」
   「次世代に何かを残したい」
```

これは表層から逆算するか、長い対話で出るニーズ。

### 実装パターン

すべてのコンテンツで:
- 表層ニーズに**応える**(表面的な悩みに答える)
- 潜在ニーズに**触れる**(「実はあなたは○○を求めているのでは?」)
- 究極ニーズに**寄り添う**(「あなたの人生にとって○○は重要ですよね」)

## ファネル検出

読者がどのファネル位置にいるかを判定し、適切な CTA を配置します。

### ファネルステージ

```
ステージ 1: 認知(Awareness)
   - 課題の存在を認識し始めた
   - 適切な CTA: フォロー、メルマガ登録

ステージ 2: 興味(Interest)
   - 解決策を探している
   - 適切な CTA: 資料DL、無料ウェビナー

ステージ 3: 検討(Consideration)
   - 複数の選択肢を比較
   - 適切な CTA: 無料相談、デモ

ステージ 4: 意図(Intent)
   - 具体的に購入を検討
   - 適切な CTA: 個別MTG、トライアル

ステージ 5: 評価(Evaluation)
   - 最終決定の段階
   - 適切な CTA: 契約相談、最終提案

ステージ 6: 購入(Purchase)
   - 購入決定
   - 適切な CTA: 申込フォーム
```

## 多段 CTA 配置

1 つのコンテンツに複数の CTA を、段階的に配置します。

### 標準的な配置パターン

```
記事冒頭(序盤 CTA): 軽い行動
   - SNS フォロー
   - メルマガ登録
   ↓
記事中盤(中盤 CTA): 中程度の行動
   - 資料 DL
   - 無料ウェビナー
   - 関連記事への誘導
   ↓
記事終盤(本命 CTA): 強い行動
   - 個別相談
   - 申込
   - 契約
```

### 実装例

```markdown
# AIエージェントチームでひとり社長が月商100万を超える方法

[本文導入...]

(序盤 CTA)
※ 関連トピックは LINE で配信中。プロフィール欄からどうぞ。

[本文中盤...]

(中盤 CTA)
※ 「8体エージェント設計の詳細」は無料 PDF で配布中。
   こちらから受け取ってください: [URL]

[本文後半...]

(本命 CTA)
※ Virtus Founding Member の応募は 30 名限定。
   興味がある方は、以下から無料診断を受けてください: [URL]
```

## エンゲージメント設計

読者を「読み続けさせる」ための仕掛け。

### フックの種類

```
1. 数字フック
   「90% の経営者が知らない」
   「3 ヶ月で 245% 成長した方法」

2. 反論フック
   「実は SNS だけでは限界です」
   「SNS 運用の常識が間違っている理由」

3. 物語フック
   「私が建設業から AI 開発に転身した理由」
   「Founding Member の山田さんが半年で月商 200 万を実現した話」

4. 警告フック
   「これを知らないとあなたは取り残される」
   「2026 年下半期、AI 未対応の事業者は淘汰される」
```

### つなぎフレーズ

```
「ここで重要なのは...」
「実はここに本質があります」
「率直に言うと...」
「具体例を見てみましょう」
「ここからが本題です」
```

## 継続的勢いの作り方

1 つのコンテンツで完結させず、シリーズ化する。

### シリーズ展開パターン

```
パイロット記事:
   全体像を提示、各論への興味を引く

第 1 弾: 〇〇編
   特定領域を深掘り

第 2 弾: △△編
   別領域を深掘り

第 3 弾: 統合編
   全体を再統合、本命 CTA
```

## 実装フロー

```python
def write_with_dream_framework(topic, target_audience, brand_dna):
    """
    DREAM WRITING フレームワークでコンテンツ生成
    """
    # Step 1: ファネル検出
    audience_funnel_stage = detect_funnel_stage(target_audience)
    
    # Step 2: 三層ニーズ分析
    needs = {
        "surface": identify_surface_needs(target_audience, topic),
        "latent": identify_latent_needs(target_audience, topic),
        "ultimate": identify_ultimate_needs(target_audience, topic),
    }
    
    # Step 3: 構造設計
    structure = build_structure(
        funnel_stage=audience_funnel_stage,
        needs=needs,
    )
    
    # Step 4: フック選定
    hook = select_hook(target_audience, topic)
    
    # Step 5: CTA 配置
    ctas = place_multi_stage_ctas(audience_funnel_stage, structure)
    
    # Step 6: 執筆
    content = write_content(
        structure=structure,
        hook=hook,
        ctas=ctas,
        brand_dna=brand_dna,
    )
    
    return content
```

## 適用シーン

DREAM WRITING は以下に特に有効:

第一に、**長文コンテンツ**(note、ブログ記事 1500 字以上)
第二に、**LP**(ランディングページ全体)
第三に、**ステップメール**(7-14 通のシリーズ)
第四に、**ホワイトペーパー**(20-50 ページ)
第五に、**ウェビナー台本**(30-60 分)

短文(X投稿、Instagram キャプション)では、シンプルに Garai Tone のみで十分です。
